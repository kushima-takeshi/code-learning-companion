# 02. 公開PRの取り込み

## 目的

公開PRのURLを教材として取り込み、問題生成・復習で同じ内容を参照できるスナップショットを保存する。

## 入力と対象外

- 必須入力: GitHubの公開PR URL
- 任意入力: Cursor会話のMarkdownファイル
- 対象外: 非公開PR、GitHub App、開発中の自動収集、Cursor会話の自動取り込み

## 利用フロー

```text
PR URLを入力 → URL・公開状態を検証 → PRを取得 → スナップショットを保存 → 学習候補生成へ進む
```

## 取得・保存する情報

- URL、リポジトリ名、PR番号、タイトル、本文、作成者、状態
- 取り込み時点のhead commit SHAと取得日時
- 差分、変更ファイル、コミット情報、レビューコメント
- 任意アップロードされたCursor Markdown

大きな本文はObject Storage、検索・関連付け用メタデータはPostgreSQLに保存する。

## 周辺コード

差分だけで根拠が足りない時だけ、次の順で追加取得する。

1. 変更箇所の前後のコード
2. 同一ファイルで直接参照される型・関数・定数の定義
3. 必要な場合だけ呼び出し元などの関連ファイル

リポジトリ全体を一律に取得してはならない。

## エラーと受け入れ条件

| 条件 | 扱い |
|---|---|
| URL形式が不正 | 公開PR URLの入力を案内 |
| 非公開・存在しない・取得不能 | 公開PRのみ対応と表示し、保存しない |
| GitHub APIの一時エラー | 保存せず、再試行を案内 |
| Cursorファイルが不正 | PR取り込みは継続し、ファイルだけ再選択を案内 |

- 自分・他者を問わず公開PRをURLで取り込める
- GitHub上のPRが後から変わっても、保存済み教材は変わらない
- Cursorファイルなしでも取り込める
