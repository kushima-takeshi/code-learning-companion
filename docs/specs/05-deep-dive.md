# 05. AIツール内の深掘りと学習要点（現行）

## 目的と対象外

問題の文脈を保ったまま、普段のAIツールで疑問を掘り下げる。
アプリ独自のチャット画面、GoからのLLM呼び出し、会話全ログの常時収集は初期対象外。

## フロー

問題・回答・必要なら手元の教材を参照してAIと対話 → ユーザーが要点・未解決点と送信内容を確認する → 選んだ学習記録をアプリへ保存 → 後日閲覧・再開時に取得。

## 仕様

- 回答前・途中・解説後のいずれでも対話できる。回答前に受けたヒントは回答履歴に区別して残す。
- LearningNoteに所有者、学習セットまたは問題との関連、要点、未解決点、作成日時を保存する。
- 深掘りの会話原文は自動保存しない。既存PR取り込みで任意に会話Markdownを添付する場合も明示的な選択とし、AI要約と区別する。
- 要点・未解決点にも非公開情報が含まれ得る。保存前に送信内容を確認し、除外・一般化または保存中止できるようにする。
- 深掘りだけでは問題再生成、理解度、復習予定を変更しない。再回答・再判定は明示的な別操作とする。
- 通常の候補・問題生成には関連する保存要点を使い、深掘りの全ログを一律に送らない。

## 受け入れ条件

- 元教材のアプリ保存なしでも、AIツール内で問題・回答・必要な手元の教材をもとに深掘りできる。
- 保存を選んだ要点・未解決点をアプリで閲覧し、別チャットから取得できる。
- 他ユーザーの要点にアクセスできない。
- 深掘りしただけで学習状態・復習予定が書き換わらない。
