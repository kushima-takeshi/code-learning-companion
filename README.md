# Code Learning Companion

AIの補助で開発したコードを、自分で説明・修正できる理解へつなげる学習サービス。

ユーザーのAIツール内の自作スキルで、PR・コード・会話を使って出題・回答・解説を進める。
公開PRを作成せず、手元のコードや差分からも学習を始められる方針とする。
このアプリは、ユーザーが送信内容を確認した問題・回答・フィードバック等の学習記録を保存し、履歴閲覧、途中再開、復習予定・通知を担当する。元コードや会話全文は自動収集しない。

## 現在の段階

開発基盤、GitHub OAuth、公開PR取り込みまでの既存実装を活かし、第二案へ方針を整理した。
スキル連携と学習記録・復習・通知は未実装。公開PRは任意の入口として残す。次は元教材の保存を必須にしない接続・保存契約の詳細設計。
第二案の細かな提案値はまだ未確定であり、実装済みの機能と区別する。
