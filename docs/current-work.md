## 再接続サーバー処理の確認結果（2026-11-02 昼）

- マイグレーション6に再接続操作を保存する。旧新トークンの所有者一致を複合外部キー、同じ旧トークンの進行中／完了済み1件を部分一意制約で保証する。原本はハッシュだけを保存し、原本を発行成功応答以外で返さない。
- 旧トークン行を先にロックし、開始・確認・完了・やり直しを直列化する。6件の同時開始で新規発行1件、6件の同時完了で同じ完了日時、完了とやり直しの競合で片方だけ成功することを実DB確認した。未完了の新トークンを再接続対象にする連鎖は409で拒否する。
- `POST /connection-tokens/{id}/reconnections`、`GET /connection-reconnections/{id}`、`POST /connection-reconnections/{id}/complete`・`restart`を既存Web認証・CSRF保護へ接続。本人分離、Bearerだけの拒否、パス検証、本文／クエリの拒否、4 KiB上限、no-store、原本の非再表示を実DB検証した。API契約は[仕様07](specs/07-agent-connection.md)に記録。
- 新トークンの`GET /learning-records`成功を確認状態へ記録し、0件も成功とする。HEAD・不正クエリ・旧／別トークン・保存／詳細取得・DB障害では確認しない。確認状態だけでは旧トークンを失効しない。
- Webの完了要求で旧トークンの失効と完了状態を原子的に保存する。やり直しは未完了の新トークンの失効・退役・新規発行を原子的に行う。DBの更新／発行失敗を注入し、旧状態・旧トークン・前の新トークンを保つロールバックを確認した。古い操作からの完了／やり直しは409で拒否する。
- 未完了24時間ちょうどから、新トークンを認証時に拒否する。期限直前／ちょうど、確認後でも未完了の期限切れ、HTTPの保存・一覧・詳細の401、旧トークンの維持、完了後の90日期限の維持を確認した。定期整理に依存しない。
- TDDで内部処理の未実装コンパイル失敗、HTTP入口未登録の404、一覧成功の確認連携未実装によるpending／200の失敗を確認後、それぞれ実装してPASSした。
- Docker内で両パッケージの実DB接続先を指定した`go test ./... -count=1`と`go vet ./...`が成功。追加の完了ロールバック／同時完了も含め、`go test -race ./internal/connectiontoken ./internal/learningrecord -count=1`が実DBで成功。他パッケージの外部DB・MinIOを使うオプトイン統合テストは未設定・未実行。
- 専用スキーマのup/down/upとアカウント削除CASCADEを確認。downによる未完了新トークンの復活も防ぐ。通常開発DBはversion=4・dirty=false、テストスキーマ残存0。通常DBへの5／6適用・実行中APIの再起動・ブラウザ／MCP操作は行っていない。

## 決まっている方針

- 自作スキルで候補・出題・回答・判定・解説を進める。アプリは記録・再開・復習・通知を担当する。
- GoからユーザーのAI APIキーを使って出題しない。AI側の認証情報を預からない。
- 手元のコード・未コミット差分・許可された会話から学習できる。公開PRの作成・公開・取り込みは必須にしない。
- 元コードや会話全文は自動収集しない。保存の中心は問題・回答・フィードバックと関連・進捗・復習に必要な情報。選択した学習要点も保存できる。
- 問題・回答・フィードバックにも非公開情報が混ざり得る。送信前に内容を確認し、除外・一般化または保存中止できる形にする。具体的な手順は未決。
- AIツールで読むこととアプリへ送ることを分ける。スキルの端末上での利用は、モデル推論の端末内完結を意味しない。
- 既存の公開PR取り込み・会話Markdown添付は明示的に選ぶ任意の入口として残す。
- 保存済み教材への根拠参照は任意。使用時は所有者・存在・範囲を検証し、抜粋本文を重複保存しない。手元の出典をサーバーが検証済みとは扱わない。
- 復習・再開は保存済み学習記録を基本にする。不足する元コード・会話は本人に再提示を依頼し、復元できるとは案内しない。
- 問題作成・出題・回答・判定・フィードバックは自作スキルとユーザーのAIエージェント上で進める。学習中は保存処理・保存状態の通知を行わない。学習後、ユーザーが保存する段階で初めて保存処理を行う。
- アプリからの再開・復習予定は保存済み記録に限る。未保存内容の永続保持や復元は保証しない。復習時は初回の問題・回答を上書きしない。
- 常駐収集・他プロジェクト連携は初期対象外。
