## 決まっている方針

- 自作スキルで候補・出題・回答・判定・解説を進める。アプリは記録・再開・復習・通知を担当する。
- GoからユーザーのAI APIキーを使って出題しない。AI側の認証情報を預からない。
- 手元のコード・未コミット差分・許可された会話から学習できる。公開PRの作成・公開・取り込みは必須にしない。
- 元コードや会話全文は自動収集しない。保存の中心は問題・回答・フィードバックと関連・進捗・復習に必要な情報。選択した学習要点も保存できる。
- 問題・回答・フィードバックにも非公開情報が混ざり得る。送信前に内容を確認し、除外・一般化または保存中止できる形にする。具体的な手順は未決。
- AIツールで読むこととアプリへ送ることを分ける。スキルの端末上での利用は、モデル推論の端末内完結を意味しない。
- 既存の公開PR取り込み・会話Markdown添付は明示的に選ぶ任意の入口として残す。
- 保存済み教材への根拠参照は任意。使用時は所有者・存在・範囲を検証し、抜粋本文を重複保存しない。手元の出典をサーバーが検証済みとは扱わない。
- 復習・再開は保存済み学習記録を基本にする。不足する元コード・会話は本人に再提示を依頼し、復元できるとは案内しない。
- 問題作成・出題・回答・判定・フィードバックは自作スキルとユーザーのAIエージェント上で進める。学習中は保存処理・保存状態の通知を行わない。学習後、ユーザーが保存する段階で初めて保存処理を行う。
- アプリからの再開・復習予定は保存済み記録に限る。未保存内容の永続保持や復元は保証しない。復習時は初回の問題・回答を上書きしない。
- 常駐収集・他プロジェクト連携は初期対象外。
