# 06. データ保持・削除・公開ベータ

## 保持

PRスナップショット、問題・回答・苦手理由、深掘り会話、保存した学習要点は、ユーザーが削除するまで保持する。MVPでは自動削除期限を設けない。

## PRの学習データ削除

`このPRの学習データを削除`では、以下を完全削除する。

- PRスナップショット
- そのPR由来の候補、学習セット、問題、回答、苦手理由
- 復習予定・復習履歴
- そのPRを起点にした深掘り会話と保存要点
- 添付したCursor会話ファイル

削除前に、復元不可であることを明示して最終確認する。技術タグなどの分類名だけは残ってよいが、PRとの関連は削除する。

## アカウント削除

アカウント削除では、当該ユーザーに属する全データとObject Storage上の関連ファイル、設定、セッションを完全削除する。復元はできない。

## 公開ベータと利用制限

- 誰でもGitHub OAuthでログインできる
- 公開PRだけを扱う
- PR解析は1ユーザーあたり1日5件まで
- LLM呼び出しは1ユーザーあたり1分10回まで
- 上限値は環境設定で変更できる

READMEまたはアプリ内で、公開PRのみ対応すること、PRと任意添付のCursor会話をOpenAIへ送ること、APIキーを保存しないこと、削除方法を明示する。

## 受け入れ条件

- PR削除後、そのPRに紐づくデータとObject Storage上の本文を参照できない
- アカウント削除後、当該ユーザーのデータを参照できない
- 上限を超えたPR解析・LLM呼び出しは実行されず、理由を表示する
