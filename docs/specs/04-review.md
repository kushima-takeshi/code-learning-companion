# 04. 復習

## 目的

初回にPRから作成した問題セットを、時間を置いて別角度から確かめる。

## 復習単位とスケジュール

復習対象は、あるPRから選んだ学習候補とその問題セットである。技術タグ全体を横断してまとめない。

```text
初回学習 → 3日後 → 14日後 → 30日後 → 定着済み
```

- 初回と同じPRスナップショットを根拠にする
- 問い方は初回と変える
- `できた`: 次の復習予定へ進める
- `一部できた`: 次の段階へ進めず、短い間隔で再出題する
- `もう一度`: 翌日または次回起動時に再出題する
- `判定保留`: 不正解にはせず、回答修正・解説確認・深掘り対話を選べる
- 30日後の復習まで問題なければ`定着済み`にする

## 画面とデータ

- ホームに今日が復習予定の学習セットを最大3件表示する
- ユーザーは1件を選んで復習し、新しいPRの学習へ進むこともできる
- `復習を終了`は予定から外すだけで履歴を削除しない。後から再開できる
- ReviewScheduleは、対象LearningSet、段階、次回日時、状態、最終理解度を持つ

## 受け入れ条件

- 初回学習後に3日後の復習予定を作れる
- テスト用に日時を進め、3日後・14日後・30日後の遷移を検証できる
- 復習問題は同じPR根拠を使い、初回と異なる問い方にできる
- 復習終了は履歴を削除しない
