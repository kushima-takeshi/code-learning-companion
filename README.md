# Code Learning Companion

AIが生成・補助したコードを、あとで自分で説明・判断・再利用できる技術知識へ変えるためのWebアプリケーション。

GitHubのPull Request、CursorなどでのAIとの会話、自分の回答を学習の材料にし、技術の定着を支援する。

## 現在の段階

フェーズ 0（開発基盤）、フェーズ 1（GitHub OAuth とユーザー分離）、フェーズ 2（公開 PR の取り込み）まで main に入っている。次はフェーズ 3（学習候補、問題、回答、フィードバック）。
