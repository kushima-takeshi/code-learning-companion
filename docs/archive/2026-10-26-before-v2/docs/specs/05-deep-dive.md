# 05. 深掘り対話

## 目的

問題で気になった点を、PRとコードの文脈を保ったまま自由にLLMへ質問できるようにする。

## 利用フロー

```text
問題画面 → 深掘りする → 文脈付きで自由対話 → 必要なら要点・未解決点を保存
```

## 仕様

- 回答前、回答途中、フィードバック後のいつでも開ける
- 初期コンテキストは、現在の問題、回答済みなら回答、該当コード、PR・差分・レビューコメントなどの根拠
- 生ログを保存する
- ユーザーは必要な場合だけ、自分の言葉での要点と未解決点を保存できる
- 深掘り後に問題を自動生成・再生成しない
- 深掘りによって理解度・復習間隔を変更しない
- 通常の問題生成には、生ログ全文ではなくユーザーが保存した要点だけを関連情報として使う

## データと受け入れ条件

- DeepDiveSession: 学習セットまたは問題、開始・終了日時
- DeepDiveMessage: 発言者、本文、順序、作成日時
- LearningNote: ユーザーが保存した要点、未解決点

会話本文はObject Storageに保存してよい。PostgreSQLには表示・関連付けに必要な情報を保存する。

- 問題画面のどの時点でも深掘りを開始できる
- 問題とPR根拠を初期文脈として会話を始められる
- 会話ログを後から参照できる
- 深掘りだけで問題・理解度・復習予定が変わらない
