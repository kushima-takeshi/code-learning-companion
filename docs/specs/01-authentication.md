# 01. GitHub OAuthとユーザー分離

## 目的

GitHub OAuthで利用者を識別し、学習データをユーザーごとに完全に分離する。

## 対象外

- GitHub App
- 非公開リポジトリの取得
- 組織・チーム管理

## 利用フロー

```text
未ログイン → GitHubでログイン → OAuthコールバック → Userを作成または取得 → ホームを表示
```

## 仕様

- OAuthで取得したGitHub IDを外部IDとして保存する
- 表示名・アバターは表示用の補助情報として保存してよい
- 非公開リポジトリ権限を要求しない
- セッションから現在ユーザーを特定できる
- 未ログインのユーザーは、学習データを作成・閲覧・更新・削除できない
- ログアウトでアプリのログインセッションを無効にする

## データ

| 項目 | 内容 |
|---|---|
| id | アプリ内ユーザーID |
| github_user_id | GitHubの安定した識別子 |
| github_login | GitHubユーザー名 |
| display_name / avatar_url | 表示用情報 |
| created_at / updated_at | 作成・更新日時 |

## 受け入れ条件

- 同じGitHub IDでは同じアプリ内ユーザーになる
- ユーザーAはユーザーBの学習データを取得・変更・削除できない
- 非公開リポジトリ権限を要求しない
